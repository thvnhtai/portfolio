- Tạo cảm giác dynamic và modern

- **Effort:** Trung bình

## 💡 Quick Implementation Ideas

### Typing Animation (30 phút)


### Particle Background (1 giờ)
```bash
npm install react-particles tsparticles
```

- Theme toggle component
- localStorage persistence

- Mouse tracking
