Preloader · Menu ⌘K · Easter egg — các phương án

Mỗi khung là một trang mini. Preloader: bấm ↻ REPLAY để xem lại. ⌘K: rê chuột vào khung rồi nhấn ⌘K / Ctrl+K (hoặc bấm nút ⌘K trên menu mini), dùng ↑ ↓ Enter. Easter egg: làm theo gợi ý ở góc trái dưới. Bấm "Chọn" cho mỗi phần (mỗi phần chọn 1).

1 · Preloader

P1 · Bộ đếm + rèm cam — đếm 0→100%, rèm cam kéo lên mở ra site (như bản thiết kế)
P2 · git clone — terminal chạy "git clone thvnhtai/portfolio", xong thì màn hình tách đôi mở ra
P3 · Tên tụ lại — chữ TAI NGUYEN bay vào từ khắp nơi, co lại thành chấm cam rồi chấm nở ra thành site

2 · Menu ⌘K

K1 · Command palette — hộp tìm kiếm giữa màn hình kiểu Raycast/Linear, nhóm lệnh, gõ để lọc
K2 · Terminal — dòng lệnh trượt lên từ dưới; gõ lệnh như cd projects, copy email, lang vi (có gợi ý bấm nhanh)

3 · Easter egg

E1 · Konami code — gõ ↑ ↑ ↓ ↓ ← → ← → B A: pháo giấy + "DEV MODE" hiện khung lưới và viền mọi phần tử (khoe chất frontend)
E2 · Gõ chữ "grab" — một đoàn xe máy xanh phóng ngang qua màn hình (nhắc tới Grab)
E3 · Bấm logo 5 lần — chế độ trọng lực: mọi thứ trên trang rơi xuống, rồi tự bay về chỗ cũ
